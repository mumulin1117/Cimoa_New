# Expanded 语音浮层与轮播差异审计

来源：2026-10-20 用户附件与明确要求；原始 HTML 的 Expanded 照片底部歌曲条。原约定文件不修改。

- D1：照片上目前只有歌曲条；人物语音另置于 bio 后独立白卡。改为语音优先占用照片底部同尺寸浮层，移除重复白卡；无语音保留原歌曲条。
- D2：浮层套用原歌曲条的左右 14、底部 12、内边距 8、封面/按钮 44、总高 60 设计像素；颜色全部复用既有主题。真实人物首图/语音/文稿替代附件歌曲资源，不能假播放歌曲。
- D3：原来只有手动前后切图。新增 3000ms 自动切图，手动后重新计时；后台、离页、弹层和导航暂停，恢复不追赶补播；零/单图不启动。
- D4：保留照片全图相册入口、左右切图热区、指示条、关系 CTA、原有返回与固定安全区。浮层层级高于照片热区，播放不进入相册。
- D5：共享 EventAudio 仅增加可选 scoped slot；所有原消费者默认输出与播放逻辑不变，专项回归默认语音按钮。

共享消费者清点：messages/chat、connections/sent、events/group、profile/preview、profile/edit、ProfileBioConfirmDialog 使用默认输出；ProfileVoiceIntro 是唯一新增 slot 消费者。默认分支节点/文案/事件与 adapter 未改变，浏览器实测 profile/preview 的 IndexedDB 语音播放/暂停。

本轮只验收该功能增量；附件与现有六组人物资源不同，不能以整图差异比例声称全页像素级通过。全页 visual/full 保持 pending。

## 本轮复核

- 浏览器实测：photo (20, 125.969, 353, 470.656)；voice (34, 524.625, 325, 60)，底距 12；封面/按钮 43.984。均在 1 CSS px 以内。
- 已逐区查看 browser、WKWebView、overlay、diff：照片、姓名、资料文本是既有实体差异；附件歌曲栏按用户要求变为真实语音栏；原型系统装饰不绘制。未更改本轮以外的资料排版或固定 CTA 骨架。
- 浏览器 9 项专项 + 6 项既有入口/状态回归通过；默认 EventAudio 消费者保留原文本与真实播放/暂停。
- 计时测试首轮失败来自模块先于测试时钟捕获原计时器，改为在 profile 模块加载前注入时钟；运行代码未为测试增加假计时分支。
- WKWebView 测试区分音频 play 事件与 play Promise 完成；暂停前须等待 pending 结束，不能对禁用控件连点后认定暂停失败。生产手势/媒体权限配置未放宽。
